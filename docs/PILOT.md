# 시범 운영과 데이터 10명 만들기

목표: 실제 사용자 10명 이상이 검사를 끝까지 마친 데이터를 만들고, 서비스로 이어갈 수 있는지 판단한다.

## 10명은 무엇을 해 주고, 무엇을 못 해 주나
- 해 주는 것: 검사가 끝까지 잘 끝나는지, 응답 신뢰도 경고가 너무 자주 뜨지 않는지, 강사가 등록·입력·상담 기록을 부담 없이 하는지, 학부모 리포트가 이해되는지 확인할 수 있다.
- 못 하는 것: 통계적 결론, 연령별 기준값(규준), "우리 검사가 타당하다"는 주장. 이건 30명(참고치) → 100명 이상(기준값 논의)이 되어도 전문가 검토가 필요하다.
- 앱의 **데이터** 탭에서 "검사 5종을 모두 마친 학생 수"로 진행 상황을 볼 수 있다.

## 구성 (권장)
| 유형 | 인원 | 이유 |
|---|---|---|
| 1:1 컨설팅 학생 | 3~4 | 상담 세션·문진·진단서 재진단 흐름 확인 |
| 공부방·어학원·학원(반 단위) | 4~5 | 출결, 반 관리, 학부모 링크 확인 |
| 스터디카페 이용자 | 3~4 | 입·퇴실, 이용권 만료, 이용 시간 자동 기록 확인 |
| 성인 진로 상담 | 2~3 | 커리어 프로필·지원 현황·성인용 검사 확인 |
| 베트남 사용자 | 최소 2 | 베트남어 문구·검사 문항 자연스러움 확인 |

## 시작 전 (필수)
1. 기관 이름·연락처 입력 (계정 탭) — 학부모 문서에 표시됨
2. 개인정보 처리방침·이용약관 법률 검토
3. **동의 받기**: 학습 정보 수집·이용(미성년자는 보호자), 정서웰빙 결과를 강사에게 공개할지, 통계 활용 동의(선택)
4. 베트남어 원어민 검수 (화면 문구 + 적성검사 문항)
5. 실제 서버 배포 + Anthropic API 키 연결 후 AI 기능 직접 시험

## 진행 (2~4주)
- 1주차: 등록 → 문진 → 종합검사 → 진단서 → 학부모 링크 전달
- 2주차: 목표·시간표·주간계획 사용, 출결 기록(반 단위), 상담 세션 기록
- 3~4주: 재검사 또는 재진단 1회, 강사·학생·학부모 인터뷰

## 매주 확인 (데이터 탭)
- 검사 5종 완료 수 (목표 10)
- 신뢰도 경고 비율 (높으면 문항 길이·안내 문구 점검)
- 최근 7일 활동 수 (낮으면 알림·안내 방법 점검)
- 강사가 입력에 쓴 시간 (직접 물어보기)

## 데이터 다루는 원칙
- 통계·연구에 쓰려면 학생(또는 보호자)의 **통계 활용 동의**가 있어야 한다. 동의한 학생만 이름 없이 내려받을 수 있다.
- 정서웰빙 결과는 내려받기에서 제외된다.
- 결과를 외부에 발표하기 전에 전문가 검토를 받는다.
