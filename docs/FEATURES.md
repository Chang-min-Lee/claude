# 기능 정리 — SMART Edu 학습관리와 비교

원본 SMART Edu 학습관리(아티팩트)의 화면·기능과 이 앱을 하나씩 대조한 표입니다.
✅ 있음 · ➕ 이 앱에만 있음 · ⚠ 다르게 구현 · ❌ 아직 없음

## 1. SMART Edu에 있던 기능

| 영역 | SMART Edu | 이 앱 |
|---|---|---|
| 홈 / 대시보드 | 학생별 대시보드, 통계 타일, D-day 띠 | ✅ 홈(히어로·타일·오늘 시간표·D-day·학습 달력·배지) |
| 학생 전환 | 상단 학생 선택기 | ⚠ 학생 목록 → "열기"로 전환 (강사 콘솔) |
| 종합검사 6종 | 흥미·성격·가치관·학습역량·자기주도·정서웰빙 (149문항) | ✅ 같은 문항·채점 규칙, 한국어+베트남어 |
| 응답 신뢰도 / 정서웰빙 안내 | 배너 + 확인 처리 | ✅ 신뢰도 경고, 정서웰빙 주의 구간, 동의 기반 공유 |
| 검사별 AI 상세 해석 | 모달 + AI 해석 | ✅ 결과 화면의 "AI 상세 해석" (API 키 필요) |
| 재검사 변화 | 추이 그래프 | ✅ 직전 대비 ▲▼ + 종합 결과 |
| 학습목표·과제 | 체크리스트, 주간 제출·기록 | ✅ 할 일 + 주간 마감 기록 |
| 시간표 | 드래그로 입력하는 주간 그리드 | ✅ 동일 방식 + AI 시간표(기존 일정 피하기) |
| 주간 학습계획표 | 초록/노랑/빨강 이행 표시, 제출, 기록 | ✅ |
| 목표·D-day·이정표 | 타임라인 | ✅ |
| 성적 | 입력, CSV 가져오기, 추이 그래프 | ✅ 입력, 붙여넣기 가져오기, 추이 그래프 |
| 학부모 리포트 | 인쇄용 문서, 베트남어 번역 | ✅ 한국어/베트남어, 인쇄·PDF, **로그인 없는 공유 링크** |
| 종합 진단서 | 회차별(초기/재진단) 조회, 이전 대비 변화 | ✅ 회차 기록 + 검사 점수 변화 표 |
| 강사용 리포트 | 조치 항목 | ✅ 강사용 탭(조치 항목·코멘트) |
| 강사뷰(학생 목록) | 필터, 일괄 선택, 주간 요약 복사 | ✅ + 오늘 살펴볼 학생 타일, 선택 학생 일괄 메시지 |
| 학생 등록·입력 | 한 화면에서 많은 항목 입력, CSV 일괄 | ✅ 학생 입력 탭 8개 섹션, 일괄 등록(+활성화 코드 CSV) |
| 운영 모델 | 어학원/공부방/컨설턴트별 문구 | ⚠ 운영 모델 선택 저장 + AI 진단서에 반영 (화면 문구는 공통) |
| 강사 계정 | 마스터+담당 강사, PIN | ✅ 관리자/강사 계정(이메일+비밀번호), 담당제 접근 제어 |
| 출석 체크인 | 학생용 체크인 화면 | ✅ 출석 체크인 (홈) |
| 학부모 발송 | 발송 기록, 링크 복사 | ⚠ 공유 링크 발급·복사·재발급·해제 (실제 메일/문자 발송은 없음) |
| 데이터 저장 | 아티팩트 DB | ✅ SQLite + 백업 스크립트 |

## 2. 이 앱에만 있는 기능 ➕

- 학생 본인 화면(초등~성인 눈높이별 말투·검사), 진로 흥미 빠른 검사(초등)
- 한국어 / 베트남어 전환, 설치형 앱(PWA), 오프라인 화면 유지, 다크 모드
- AI 코치, AI 퀴즈, 틀린 문제 복습
- 메시지(학생 ↔ 강사), 상담일지(강사 전용)
- 학습 달력(히트맵), 배지, 연속 학습일
- 보호자 계정(읽기 전용), 비밀번호 재설정(강사 발급 일회용 코드)
- CSV 내보내기, 기관 이름·연락처(문서 머리글에 표시), 개인정보 처리방침·이용약관 양식, 가입 시 개인정보 동의
- 저장 상태 알림(저장됨 / 실패 시 자동 재시도)

## 2-1. 사업 목적별 (1:1 컨설팅 / 공부방·어학원·학원 / 성인 진로)

| 목적 | 필요한 것 | 상태 |
|---|---|---|
| 1:1 컨설팅 | 초기 문진, 상담 세션(주제·과제·다음 상담일), 진단서(재진단 비교), 학부모 링크 | ✅ 상담 문진, 세션 기록(과제를 학생 할 일로 전송, 다음 상담일 안내), 진단서 회차 |
| 공부방·어학원·학원 | 반 개념, 출결, 학부모 연락처, 재원/휴원/퇴원, 일괄 등록·메시지 | ✅ 반 이름, 반별 출결(전원 출석·저장), 출석률, 상태, 학부모 정보, 일괄 등록·메시지 |
| 스터디카페 | 입·퇴실, 좌석, 이용권(만료일), 이용 시간 기록, 학부모 리포트 | ✅ 입퇴실 화면(강사 카운터) + 학생 홈 셀프 입·퇴실, 좌석·이용권 만료 알림, 퇴실 시 이용 시간이 학습 기록에 자동 반영 |
| 성인 진로 컨설팅 | 커리어 프로필, 지원 현황, 성인용 검사·진단서 | ✅ 커리어 탭(직무·희망·역량·이유·제약), 지원 트래커 |
| 데이터 축적 | 진행 현황, 동의, 익명 내려받기 | ✅ 데이터 탭(검사 5종 완료 수, 신뢰도, 재검사), 통계 활용 동의, 익명 CSV |

## 3. 아직 없는 것 ❌ (사업 전에 결정해야 할 것)

- **결제·구독** (학원별 요금제, 학생 수 제한)
- **여러 기관 분리(멀티 테넌트)**: 지금은 서버 1대 = 기관 1곳
- **이메일/문자/카카오·Zalo 알림**: 학부모에게 자동 발송, 비밀번호 재설정 메일
- **운영 모델별 화면 문구**(어학원·공부방·컨설턴트에 맞춘 용어)
- 스터디카페: 좌석 배치도·예약, 키오스크/QR 입퇴실, 이용권 결제·자동 만료 처리, 이용 시간 순위(미성년자 개인정보 때문에 일부러 미포함)
- 수납·수강료 관리, 시간표 기반 반 수업 일정, 학부모 앱 푸시
- 이력서·자기소개서 첨삭 도구 (지금은 AI 코치로 대화)
- 관리자용 사용 통계·감사 로그
