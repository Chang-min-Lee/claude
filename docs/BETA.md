# 베타 테스트 준비 체크리스트

기간: 2~4주 · 인원: 10명 이상 (구성은 [PILOT.md](PILOT.md))

## A. 시작 전 (내가 할 일)
- [ ] 배포 완료, `/healthz` 확인, 재시작 후 데이터 유지 확인 ([DEPLOY.md](DEPLOY.md))
- [ ] 관리자 비밀번호 변경, 기관 이름·연락처 입력
- [ ] AI 키 연결 후 AI 코치·퀴즈·진단서·검사 해석을 직접 한 번씩 (한국어 + 베트남어)
- [ ] 개인정보 처리방침·이용약관 법률 검토 (`주소/?legal=privacy`)
- [ ] 베트남어 원어민이 화면·검사 문항 읽어 보기
- [ ] 동의서 준비 (아래 양식): 미성년자는 보호자 서명
- [ ] 강사 계정 만들기 (강사 관리), 강사에게 사용법 10분 설명
- [ ] 백업 파일 한 번 내려받아 보관

## B. 참가자 초대 (복사해서 쓰세요)
**강사·학생 (한국어)**
> 안녕하세요! 새로 만든 진로·학습 관리 프로그램을 2~4주 함께 써 보실 분을 찾고 있어요. 아직 시험 중이라 어색한 부분이 있을 수 있고, 불편한 점을 알려 주시는 게 가장 큰 도움이에요. 주소: {주소} / 화면 왼쪽 아래(모바일은 위쪽)의 💬 버튼으로 언제든 의견을 보내 주세요. 개인정보는 동의 범위 안에서만 쓰고, 언제든 삭제를 요청하실 수 있어요.

**Tiếng Việt**
> Xin chào! Chúng tôi đang thử nghiệm chương trình hướng nghiệp và quản lý học tập mới và mong bạn dùng thử 2–4 tuần. Chương trình còn đang thử nghiệm nên có thể chưa hoàn hảo; ý kiến của bạn rất quý giá. Địa chỉ: {địa chỉ}. Bạn có thể gửi ý kiến bất cứ lúc nào bằng nút 💬 ở góc dưới bên trái (trên điện thoại ở phía trên). Thông tin cá nhân chỉ được dùng trong phạm vi bạn đồng ý và bạn có thể yêu cầu xóa bất cứ lúc nào.

**학부모**
> 자녀의 학습 리포트를 링크로 보실 수 있어요(로그인 필요 없음): {링크}. 이 링크는 자녀의 학습 현황만 보여 주며, 마음 상태나 상담 내용은 포함되지 않아요.

## C. 동의서 양식 (법률 검토 후 사용)
1. 수집 항목: 이름(별명), 학년, 학습 목표, 검사 응답·결과, 성적, 시간표, 출결, 상담 기록
2. 이용 목적: 진로·학습 컨설팅, 리포트 작성, 서비스 개선
3. 보유 기간: 베타 종료 후 ___일 / 삭제 요청 시 즉시
4. AI 처리: AI 기능 사용 시 필요한 최소 정보가 AI 서비스(Anthropic)에 전달됨
5. [ ] (필수) 위 내용에 동의합니다
6. [ ] (선택) 정서웰빙 검사 결과를 담당 강사가 볼 수 있어요
7. [ ] (선택) 이름 없이 통계로 활용하는 데 동의합니다 (→ 학생 입력 > 기본 정보의 체크)
8. 미성년자(만 14세 미만 필수): 보호자 성명·서명·연락처

## D. 참가자별 시나리오 (직접 해 보게 하기)
- **강사**: 학생 등록 → 기본 정보·문진 입력 → 종합검사 진행 도와주기 → 진단서 만들기 → 학부모 링크 보내기 → 상담 세션 기록 → 다음 날 "확인 필요" 카드 보기
- **학생**: 가입/활성화 → 검사 → 목표·시간표 → 홈에서 할 일·다음 상담 확인 → (스터디카페) 입·퇴실
- **학원·공부방**: 반 만들기 → 출결 → 결석 많은 학생 안내 확인
- **성인**: 커리어 프로필 → 검사 → 지원 현황 기록 → 상담
- **학부모**: 링크로 리포트 열어서 이해되는지

## E. 매주 점검 (내가 할 일)
- [ ] **데이터 탭**: 검사 5종 완료 수, 신뢰도 경고 비율, 최근 7일 활동
- [ ] **베타 의견함** (데이터 탭 아래): 처리 표시 → 다음 수정 목록으로
- [ ] 백업 파일 내려받기
- [ ] 참가자 5분 통화: "이번 주 가장 불편했던 것 1개, 가장 좋았던 것 1개"

## F. 종료 판단 (베타 후)
| 질문 | 기준(예시) |
|---|---|
| 검사를 끝까지 마친 학생 | 10명 이상 |
| 강사가 등록·입력에 쓴 시간 | 학생 1명당 10분 이내 |
| 학부모 링크 열람 | 절반 이상이 열어 봄 |
| "계속 쓰겠다" | 강사 대부분 |
| 치명적 오류 | 0건 (데이터 손실·다른 사람 정보 노출) |

## G. 알아 둘 한계
- 검사 문항·채점은 자체 설계라 **공인 검사가 아님**. 화면·문서에 참고용이라고 표시돼 있어요.
- 학생 본인 폰의 입퇴실은 조작될 수 있어요.
- 이메일·문자 자동 발송, 결제, 여러 기관 분리 운영은 아직 없어요.
