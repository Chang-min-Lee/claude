# 🧭 진로AI 코치

초등학생부터 대학생·성인까지 사용할 수 있는 **진로탐색 + 학습관리 + AI 코치** 웹앱.

## 실행
```bash
export ANTHROPIC_API_KEY=sk-ant-...   # 없으면 AI 코치만 비활성 (나머지는 동작)
npm start                             # http://localhost:3000
```
Node 18+ 필요, 외부 의존성 없음. 모델은 `CLAUDE_MODEL`로 변경 가능.

## 기능
- **연령별 맞춤**: 초등/중등/고등/대학/성인에 따라 문항 문장, 추천 직업, 다음 행동, AI·퀴즈 수준과 말투가 달라짐
- **진로탐색**: RIASEC 흥미검사(12문항) → 상위 2유형, 추천 직업, 다음 행동
- **학습관리**: 할 일 체크, 공부시간 기록·25분 타이머, 주간 그래프, 연속 학습일
- **AI 학습 계획**: 목표·기간·주당 시간을 입력하면 주차별 할 일을 생성 (API 키가 없으면 기본 템플릿)
- **AI 퀴즈**: 주제를 입력하면 객관식 문제·해설 생성, 점수 기록 (API 키 필요)
- **AI 코치**: 프로필·검사결과·할 일을 반영한 Claude 상담 (API 키는 서버에만 보관)
- **계정·동기화**: 이메일 가입/로그인, 학습 데이터 자동 저장으로 여러 기기에서 이어서 사용 (로그인 없이도 사용 가능, 이 경우 브라우저에만 저장)
- **보호자/교사 대시보드**: 학습자가 준 8자리 코드로 연결 → 공부 시간·목표·흥미유형·퀴즈 점수 요약 확인.
  **AI 상담 대화는 공개되지 않으며**, 학습자가 언제든 코드 재발급·연결 해제 가능

## 개인정보·운영 참고
- 비밀번호는 scrypt로 해시, 세션 토큰은 해시로 저장, 로그인/AI 호출은 IP별 속도 제한
- 데이터는 `data/db.json`(환경변수 `DATA_DIR`)에 저장 — 소규모/시범 운영용. 서비스 확장 시 DB(PostgreSQL 등)로 교체 권장
- 만 14세 미만 아동 대상 서비스는 법정대리인 동의(개인정보 보호법) 절차가 필요하므로 정식 운영 전 검토하세요
- HTTPS 뒤에서 운영하세요 (토큰이 Authorization 헤더로 전달됨)
